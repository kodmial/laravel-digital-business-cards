# Security Policy

## Supported versions

Security fixes are provided for the latest released version.

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| < 1.0 | No |

## Reporting a vulnerability

Use the repository's **Security** tab and **Report a vulnerability** to submit a
private vulnerability report when private vulnerability reporting is enabled.

Do not include exploit details, credentials, personal data, or other sensitive
information in a public issue. If private vulnerability reporting is not yet
available, open a non-sensitive issue asking the maintainers to provide a
private reporting channel.

Include the affected version, impact, reproduction steps, and any suggested
mitigation. Please allow the maintainers reasonable time to investigate before
public disclosure.
